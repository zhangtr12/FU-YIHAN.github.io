ASTRA — Space Exploration Website  (CMNS2016 Final Project)
===========================================================

FILES
  index.html      Home — hero + the interactive branching video (Assignment 1)
  timeline.html   Animated timeline of space milestones
  missions.html   Mission cards + an embedded "key missions" video
  chat.html       Space Chat — a working rule-based chatbot (Assignment 2 content)
  gallery.html    Interactive photo gallery with a lightbox
  styles.css      Shared design/styling for ALL pages (edit colours/fonts here)
  script.js       Shared menu + timeline animation
  images/         Put your photos here (NASA public-domain or your own)
  videos/         (Optional) a looping hero background video

TO PREVIEW LOCALLY
  Keep every file in the SAME folder, then double-click index.html.

WHAT TO FILL IN (search the files for these markers)
  1. index.html  -> VIDEO_IDS  : paste your 3 YouTube video IDs
  2. missions.html-> PASTE_MISSIONS_VIDEO_ID : your missions video ID
  3. chat.html    -> KNOWLEDGE  : your Assignment 2 chatbot Q&A
  4. gallery.html -> data-img   : your image file paths
  5. timeline.html/missions.html -> .placeholder : swap for <img> when ready
  6. Every page footer -> [Your Name] / Student No. / Credits list

YOUTUBE
  Upload each video as "Unlisted" (NOT Private), or the embeds won't play.

REFERENCING (assignment requirement)
  This template & interactivity code is AI-assisted — note that in the
  Credits section of the footer. Credit every image and audio source too.
